# 原型归档状态

以下 HTML 文件是阶段 0 已批准的视觉基线。在开始 Vue 实现之前，将设计对话的最终输出精确保存到这些路径下：

| 目标文件 | 状态 | 备注 |
| --- | --- | --- |
| `agent-workspace.html` | 待归档 | 使用最终的 v0.2 工作区设计。Vue 实现中保持中间 `generate_diff` 行紧凑；完整差异保留在右侧抽屉中。 |
| `workspace-home.html` | 待归档 | 使用仅包含最近项目和可搜索全部工作区右侧抽屉的最终版本。 |
| `session-history.html` | 待归档 | 使用最终重构版本：紧凑时间线列表加右侧详情抽屉；待处理任务使用"继续审查"。 |
| `settings.html` | 待归档 | 使用最终的两列设置中心设计，带分类导航。 |

## 必需的文件名

将每个设计的最终独立 HTML 文件以上述精确的目标文件名复制到此目录。不得将原型 HTML 放入 `frontend/src/`。

## 实现的事实依据

当原型与架构文档存在差异时，以架构文档为准确定行为，以原型为准确定视觉语言。在实现前，将任何新批准的交互变更同时记录在此文件和相关的架构章节中。
