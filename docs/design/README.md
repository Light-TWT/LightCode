# LightCode 设计原型

此目录包含已批准的独立 HTML 视觉原型。它们是 Vue 实现的参考资料，不得直接复制到 `frontend/src/` 中。

## 命名说明

- `agent-workspace.html`：主要的智能体任务、执行、差异审批和验证工作区。
- `workspace-home.html`：最近项目和已注册工作区的入口视图。
- `session-history.html`：项目任务历史记录，包含页内任务详情抽屉。
- `settings.html`：两列配置中心。

## 导入流程

1. 使用上述文件名保存设计对话中已批准的精确 HTML。
2. 将后续的任何视觉决策记录在同级 Markdown 文件中。
3. 使用 Vue 组件、Pinia 状态、类型化 Mock 夹具和服务接口重新实现视图。
4. 在视觉验证期间保留原型作为对比基线。

## 已确认的交互规则

- Agent Workspace 使用固定左侧栏、中央执行流和可调整大小的右侧上下文抽屉。
- 完整代码差异仅属于右侧审查抽屉。
- 待处理的变更集替换新任务输入为审查和拒绝控件。
- Workspace Home 仅列出最近工作；完整的已注册工作区列表位于可搜索的右侧抽屉中。
- Session History 显示紧凑的任务摘要；已完成、失败和已取消的任务打开页内只读详情抽屉。待审批任务通过"继续审查"操作返回 Agent Workspace。
