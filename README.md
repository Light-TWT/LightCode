# LightCode

LightCode 是一个独立实现的、本地优先的可视化编码智能体，面向有基础编程经验的开发者。

项目当前仅包含阶段 0 的规划和设计产物。第一个实现目标是一个使用类型化本地 Mock 数据的 Vue 3 + TypeScript + Vite 前端原型。

## 起步

1. 阅读[项目规则](AGENTS.md)。
2. 阅读[架构文档](docs/architecture/lightcode-local-first-agent-design.md)。
3. 按照[原型状态文档](docs/design/PROTOTYPE_STATUS.md)归档已批准的视觉原型。
4. 首先实现 `AgentWorkspaceView`，不集成后端、数据库、模型或文件系统。
